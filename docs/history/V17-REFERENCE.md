# MesHeures V17.0.0

Base : version réparée par Claude, conservée comme référence stable.

## Nouveautés
- Navigation mobile basse : Accueil / Saisie / Planning / Paie / Outils.
- Projection de quatorzaine basée sur les journées futures explicitement planifiées.
- Les journées futures non renseignées ne sont jamais inventées : elles sont signalées.
- Estimation des journées planifiées sans horaires à partir d'une moyenne récente robuste.
- Moteur de contrôle légal dédié transport sanitaire.
- Référentiel vérifié le 11/09/2026 : Code du travail + CCNTR/transport sanitaire.
- Contrôles amplitude 12/14 h, TTE 10/12 h, 48 h semaine, moyenne 46 h/12 semaines, repos et pause 20 min.
- Minima ambulanciers N1 11,89 €, N2 11,90 €, N3 12,79 € et indemnité dimanche/férié 23,90 € (avenant n°8 du 06/05/2025).
- SMIC 12,31 € brut/h au 01/06/2026.
- Taux personnel par défaut : 14,20 € brut/h hors ancienneté.
- Sauvegardes locales V17 : jusqu'à 5 points, export/import JSON versionné, sauvegarde avant restauration/import.
- Thème automatique / sombre / clair.
- Cache PWA V17 et version Android 17.0.0.

## Important
Le référentiel légal fournit des contrôles d'aide et ne remplace pas une interprétation juridique individualisée lorsque l'accord d'entreprise, le contrat ou une situation particulière ajoute des règles.
